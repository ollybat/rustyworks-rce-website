How this list is made

The website lives at ollybat/rustyworks-rce-website. When a batch of work is pushed, the commit list is written to a small JSON file next to this page and read back here: message, date, short commit id and a link to the commit. Rebuilds are not automatic - the list is as fresh as the last push.
