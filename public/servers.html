Every Rust server Spinback RCE looks after, with the state the bot last measured: answering or not, how many players are on it, the map and when it was last checked. The bot reports, this page repeats. Anything the bot has not reported is shown as not reported, because a made-up player count would be worse than an honest blank.

Reading the bot...

Adding one is a Discord step: /setup tests the address before it saves it, and every server saved there appears here.

What this page can show

It shows what the bot's own read-only status reports: the servers it has been given, whether the last connection test answered, when that test ran, and what the server said when it answered. Player counts, map names and round-trip times appear as soon as the bot reports them for each server. Nothing here can change a server, and no password, token or address the bot keeps privately is ever shown.
