How it works

Three steps, then forget about it

No account, no API keys, nothing to install on your own machine. You invite the bot, you press one command, and the features are on.

Invite Spinback to your server

Use the Add to Discord button. Discord shows you exactly which permissions are requested, and you approve them there.

Run /dashboard once

One command, owner only. Only the server owner sees it: nobody else gets a command list full of tools they cannot use.

Set things up once, play on

Zorps, economy, shop, games, drops and automation are configured from your console and then run themselves, so staff can actually play the game.

Straight answers

Questions people actually ask

Is it really free, or free until it is not?
Really free. There is no premium tier, no locked feature list and no card anywhere in the setup. Spinback is a project run by people who play on a Rust Console server, not a shop.
Will my members see a wall of commands?
No. There is one command, /dashboard, and it is registered as an administrator command. If a member types it anyway, the bot answers privately that the command is only for the server owner.
Do I have to make an account for the Kit Studio?
No. The Kit Studio, the Colour Studio and the item catalogue all run in your browser. Kits are saved in your browser storage, so they work without signing in, and you can clear them whenever you like.
Does Spinback ever need my Discord password or token?
Never. The bot is added through Discord's own authorisation screen, where you see the permissions before you approve. Nothing on this site asks for a token or a password.
What is still being built?
The skin catalogue needs real data before it shows anything, and it says so on the page instead of pretending. Live bot panels on this site stay quiet until the bot reports in. Everything the site cannot verify is labelled, not guessed.
Which Rust does this cover?
Rust Console Edition. Spinback is built and run on a 5x EU clan server, so the defaults, the loot tables and the kit multipliers are tuned around that kind of wipe.
