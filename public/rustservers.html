Server Browser

Search every official and community Rust Console server, filter it down to what you like, and check a map before you join. The browsing interface is still being built.

Set up your server

Spinback has to be in your server before anything can be set up there. Sign in and this shows, server by server, whether the bot is already in it - answered by the bot itself.

What it will do

The bot already reads the live server list; the page that puts a search box in front of it is the part still to come.

  • Official and Community servers, PlayStation and Xbox
  • Search by server name, server ID or map seed
  • Filter by region, map wipe, team size, map size and monuments
  • See gather, loot and stack rates on community servers
  • Load a map preview, then copy the server ID or share a link
