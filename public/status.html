Measured by this site

Every time anyone loads this page, the site records what the bot API answered and how long it took — from the site, not from your browser. That is what is charted here. It is honest about its own limits: samples exist only when somebody is looking, and a bar is drawn only from real checks, never filled in.

Bar height is how many checks landed in that hour; green means every one answered, ember means some failed, red means it was down, hatched means nobody looked.

      What each line means

      Linked players
      Players who have linked a Rust Console account to the bot, counted by the bot.
      Servers connected
      Game servers the bot is currently paired with.
      Guilds running the bot
      Discord servers the bot has been added to.
      Bot uptime, 30 days
      The bot’s own rolling figure for the last 30 days.
      API uptime, 30 days
      The same figure for the API that answers this page.
      Measured by this site
      Checks the site itself made while people were reading it. The response time is from the site to the bot API, so it excludes your connection — the opposite of the visit chart below it. Fewer samples mean quieter days.
      This visit
      Requests your browser made while this tab was open. Response time here includes your connection, so read the shape rather than any single spike.
      Bot heartbeat
      The timestamp the bot last reported itself alive. If it stops moving, the bot is in trouble even when the API still answers.
