Settings

Spinback reads your server’s own roles and channels, so you choose them from a list instead of hunting for ids. Nothing here needs Developer Mode: click a slot, pick the role or channel, test your RCON, save. Everything is written to the same place the Discord panels write to.

Three steps

  1. Rescan server pulls the live role and channel list from the bot.
  2. Click any slot to choose from that list — searchable, no ids to copy.
  3. Paste the settings token once, then Save changes writes all of it.

What only Discord can do

  • Approving a player’s link request (/user forcelink), because that needs to know who is asking.
  • Reading your Rust server’s own logs and config.
  • Anything the bot cannot verify — it says so rather than guessing.

Owner access

One shared secret between this site and the bot: BOT_SETTINGS_TOKEN. It is kept in this tab only, sent only to this site’s own API, and never put in a URL. Without it the page still reads everything — it just cannot write.

Setup checklist

Who may run staff commands

Staff roles

Click a slot and choose from your server’s real roles. Anyone with one of these roles may use staff commands; the owner and anyone with Administrator can always do so as well.

Where the bot reports

Log channels

Fifteen log types, one channel each. A type left off sends nothing. A channel the bot cannot post in is flagged, because a log target it cannot write to is worse than none.

RCON

Rust servers

The connections the bot talks to for player lists, kits and the health check. Passwords are write-only: you can set one, never read one back, and a saved server is tested by its id so its password never reaches a browser.

The bot allows six checks a minute, so a long list is tested slowly on purpose.

Add a Rust server

Address and RCON port come from your server’s config; the password is the one in server.cfg (rcon.password).

Emote kits

Kit settings

The bot never invents a plugin command. Leave a field blank and the matching subcommand tells you exactly what is missing.

Placeholders: {player} the gamertag, {kit} the kit name. A template with neither is kept as you typed it, not silently rewritten.

Keyboard

  • Ctrl/Cmd + S — save changes
  • Ctrl/Cmd + K — open the picker for the next empty slot
  • Esc — close a picker
  • Inside a picker: type to filter, ↑↓ to move, Enter to choose

Where each setting is enforced

  • Staff roles — checked on every command, button, menu and modal.
  • Log channels — a channel the bot cannot post in is flagged before you save.
  • Rust servers — private addresses are refused, so the bot cannot be aimed at your LAN.
  • Kits — blanks stay blanks; no plugin command is ever guessed.
  • Links — Discord-only, because approval has to know who is asking.
