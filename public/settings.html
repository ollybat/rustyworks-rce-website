How the token works

  • It is one shared secret between this site and the bot — the same string in both places.
  • This page sends it only to this site's own API, over HTTPS, on the same origin.
  • It lives in this tab's session storage. It is never written to disk and never put in a URL.
  • If it is not set on the website, loading says exactly that instead of pretending.

What changes here and what does not

  • Changes here: staff roles, log channels, saved RCON servers, kit settings and the player link list.
  • Does not change here: your Rust server's own config, or anything the bot cannot verify.
  • Server passwords are written but never read back into this page.
  • An RCON connection is only ever tested by the bot, in Discord (/setup run or /setup refresh), where it can report back honestly.
