    How these commands work

    The syntax comes straight from the official Rust Console Edition community-server documentation, in the Kit Management guide:

    • kit add "Kit name" "item" amount condition Container - run it once per item. The first time you use a kit name, the kit is created.
    • condition is 0-1, and it only matters for items that wear out. 1 is brand new.
    • Container is Main, Belt or Wear. The hotbar only holds six items, so the tool warns you if you put more than six on the belt.
    • The amount is capped by your server's stack rules, so a bigger number is trimmed rather than rejected.
    • Servers allow up to 128 kits. kit list shows what exists, kit info "Kit name" describes one, and kit remove "Kit name" "ID" removes a single item.
    • Read the official guide before you run these on a live server.

    Where the item list comes from

    The picker reads /data/items.json. Entries marked ours in the kit list were added by us from item names that are widely known in the game and carry no recorded stack size - check those names on your server before you ship a kit. The rest came from a public RUST item database, which is the reference the RCE server docs point at for item names, and they include the short name and stack size.

    Rust Console Edition runs an older build than the PC game, so a name from that database may not exist on your server yet, and we could only read part of that database. If a name is rejected, try the other form (the short name or the display name), or add your own with the button above.

    Nothing here is sent anywhere

    The kit you build is kept in your browser's own storage so it survives a reload, and it is never uploaded. No account, no tracking, and the page keeps working when your connection drops.
