Colour Studio

Generate gradient colour text in the <#RRGGBB>character format for Rust server messages, killfeed titles and embed headers. The live preview is still being built.

What it will do

Type your text, pick a palette, copy the output. Nothing to install.

  • Live preview as you type - see the gradient in real time
  • Up to 8 custom colour stops per gradient
  • 8 built-in Rust-themed presets to start from
  • Save your own palettes once saving is switched on
  • Paste existing tagged text to decode and re-edit it
Ask for it in the support server

About saving palettes

The generator itself will work signed out. Saving palettes to an account is the piece that needs a Discord sign-in, and this site only issues sessions to the owner of the server the bot runs in - the sign-in page explains exactly what that covers.
