What setup asks for

Staff Role Assignments

Step 1 of /setup server. These roles control who can use staff commands. Changes are instant.

  • 👑 Owner Role * - Owner
  • 🛡️ Co-Owner Role - Co-Owner
  • ⚔️ Head Admin Role - Head Admin
  • 🔧 Admin Role - Admin
  • 🔨 Moderator Role - Moderator
  • 🔗 Linked Role * - Linked

Owner Role and Linked Role are the required ones; Co-Owner, Head Admin, Admin and Moderator can be left blank.

Log Channel Assignments

Step 2 of /setup server. Select a Discord text channel for each log type, or create them. Leave blank to disable that log.

  • 🖥️ Server Log - #server log
  • 📟 Console Log - #rw-console
  • ⌨️ Command Log - #rw-command
  • 📤 RCON Command Usage - #rw-command-usage
  • 🔗 Linking Log - #rw-linking
  • 💀 Killfeed Log - #rw-killfeed
  • 🚁 EventFeed Log - #rw-eventfeed
  • 🎭 Emote Kits Log - #rw-emotekits
  • 🛡️ Admin Log - #rw-admin
  • 🧱 Zorp Log - #rw-zorp
  • 🌀 Teleport Log - #rw-teleport
  • 🏷️ Clan Log - #rw-clans
  • 🏇 Catch-A-Ride Log - #rw-catcharide
  • 👋 Join/Leave Log - #rw-joinleave
  • ❌ Error Log - #rw-error

Rust Server Connections

Step 3 of /setup server: the server's name, IP, RCON port and password. The connection is tested before anything is saved. 0/3 servers linked. The bot reconnects automatically within a minute.

Manage a connection afterwards with /setup edit, /setup refresh or /setup remove.
